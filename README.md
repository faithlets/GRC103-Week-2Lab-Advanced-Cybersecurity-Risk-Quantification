# GRC103-Week-2Lab-Advanced-Cybersecurity-Risk-Quantification
Assignment Overview
This project focuses on quantitative cybersecurity risk assessment techniques used to evaluate organizational risk exposure and prioritize security investments.

The assignment includes:

Risk identification and assessment
Single Loss Expectancy (SLE) calculations
Annualized Rate of Occurrence (ARO) analysis
Annualized Loss Expectancy (ALE) calculations
Risk prioritization and visualization
Cost-benefit analysis of security controls
Return on Investment (ROI) evaluation
Risk treatment planning
Executive dashboard and recommendations
